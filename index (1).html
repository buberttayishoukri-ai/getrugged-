FAQ

Questions.

Does it slow down the page?

No. A single script runs only when clicked, injects one report card in a shadow root, and disappears when closed.

Do I need to connect a wallet?

No. The score is computed from public data. A detected wallet is only used to personalise the read.

Does it work on mobile?

Bookmarklets work in Chrome and Brave on Android. On iOS Safari they're supported but harder to install — desktop recommended.

What does the score measure?

Holder concentration, dev wallet share, liquidity depth, sniper pressure and bundle activity, weighted into one 1–10 number.
